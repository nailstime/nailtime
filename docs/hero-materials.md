# Your Time for Happiness — รายการ Material

## เวอร์ชันทดลองที่ทำไว้

- TIME: ริบบิ้นซาตินมุก 3D สร้างจากโค้ด พร้อมตัวอักษร TIME ที่ขยายตาม scroll
- PAUSE: ภาพ `public/images/hero.webp` ครอปเป็นภาพแนวตั้งชั่วคราว และลดจังหวะการเคลื่อนไหว
- BEAUTY: โมเดลเล็บเจล 3D และภาพผลงาน `public/images/portfolio/1.webp` พร้อม Beauty → Happiness
- CRAFT: ซูมภาพผลงานจริง `public/images/portfolio/3.webp` แทนคลิปมือช่าง ภาพนี้เป็นงานที่เสร็จแล้ว ไม่ใช่ภาพกระบวนการทำงาน
- NAIL TIME: ชื่อแบรนด์จัดด้วยตัวอักษรชั่วคราว พร้อมปุ่มจองและดูบริการ
- Editorial หลัง Hero: ใช้ภาพผลงาน `portfolio/1.webp` ชั่วคราว จนมีภาพร้านจริง

## ควรเตรียมเพิ่ม เรียงตามความสำคัญ

1. **คลิป CRAFT**: มือช่างลงสีหรือเก็บรายละเอียด 5–10 วินาที กล้องนิ่ง แสงนุ่ม โฟกัสหน้าเล็บ ถ่าย 4K ถ้าทำได้ เก็บทั้งแนวนอน 16:9 และแนวตั้ง 9:16 ไม่มีข้อความ เพลง ฟิลเตอร์ หรือ watermark สำหรับ desktop ให้องค์ประกอบหลักอยู่ขวาเพื่อเหลือที่วางข้อความด้านซ้าย ส่งไฟล์ต้นฉบับ แล้วค่อยแปลงเป็น WebM/MP4 และทำ poster ภาพนิ่ง
2. **ภาพร้านจริง 2–3 ภาพ**: มุมกว้าง บริเวณที่นั่ง และรายละเอียดบรรยากาศ แสงธรรมชาติ จัดพื้นที่สะอาด ใช้แทนภาพ PAUSE และภาพเปิด editorial ความกว้างอย่างน้อย 2000px เก็บภาพที่มีพื้นที่ว่างรอบจุดสำคัญเพื่อครอปมือถือ
3. **ภาพเล็บ macro 3–5 ภาพ**: โทนชมพูหม่น นู้ด ไวน์ มุก หรือสีเด่นของร้าน ให้เห็นความโค้งและ reflection ถ่ายบนพื้นเรียบ โฟกัสคม แสงไม่แข็ง ส่งต้นฉบับก่อนใส่ลายน้ำ (ภาพที่มีตอนนี้มีข้อความติดอยู่ในภาพ)
4. **โลโก้จริง**: SVG เป็นหลัก หรือ PNG โปร่งใสความละเอียดสูง ทั้งสีเข้มและสีขาว เพื่อแทนชื่อแบรนด์ในฉากจบ
5. **เฉดสีประจำร้าน 3–5 สี**: ภาพ swatch หรือรหัสสี เพื่อปรับวัสดุเล็บ 3D ให้ตรงกับบริการจริง

ใช้ภาพ/คลิปของร้านที่ได้รับอนุญาตจากบุคคลในภาพ เลือกภาพมือเป็นหลัก ไม่จำเป็นต้องเห็นหน้าลูกค้า

## พฤติกรรม

เลื่อนปกติ ไม่มีการล็อกล้อเมาส์ กดชื่อฉากเพื่อข้ามได้ มีปุ่มข้ามเรื่องราวและปุ่มหยุดการขยับอัตโนมัติ ผู้ใช้ที่ตั้ง reduced motion เห็นข้อความครบทุกฉากใน layout ปกติ เมื่อ WebGL ใช้งานไม่ได้ ใช้ริบบิ้น CSS และภาพเดิมแทน
